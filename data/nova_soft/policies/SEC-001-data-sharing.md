# SEC-001 자료 공유 및 외부 전달 지침

- **문서번호:** SEC-001  
- **소관부서:** 정보보호팀  
- **적용대상:** NOVA Soft 전 임직원 (정규·계약·인턴 포함)  
- **버전:** 1.0  
- **시행일:** 2026-01-01  
- **분류:** 사내한  

---

## 1. 목적

본 지침은 회사·고객·협력사 자료의 외부 전달 시 승인·보안·기록 절차를 정하여 정보유출과 무단 공유를 방지한다.

## 2. 적용 범위

1. 이메일, 메신저, 클라우드 링크, USB, 인쇄물 등 **모든 외부 전달 수단**에 적용한다.
2. 고객사, 협력사, 개인 계정, 외부 커뮤니티로의 전달을 포함한다.
3. **AI AX팀 신입사원**을 포함한 전 직원에게 동일하게 적용한다.

## 3. 용어

| 용어 | 정의 |
|------|------|
| 외부 전달 | 회사 통제 밖 계정·시스템·매체로 자료를 보내는 행위 |
| 승인자 | 해당 업무의 **팀장**. 부재 시 **본부장 또는 사전 지정 대리자** |
| 개인정보 | 성명, 연락처, 주민등록번호 등 개인을 식별할 수 있는 정보 |
| 고객데이터 | 고객사로부터 제공받거나 프로젝트에서 생성된 업무 데이터 |

## 4. 외부 전달 절차

### 4.1 사전 확인

전달 전 다음을 확인한다.

1. 자료에 **개인정보·고객데이터·비밀번호·API 키·내부 비용/견적**이 포함되는지
2. 전달 목적과 수신자가 업무상 필요한지
3. 최소 필요 범위만 전달하는지 (불필요 필드·시트 제거)

### 4.2 외부 전달 승인

1. 외부로 자료를 보내기 **전에** 승인자의 **사전 승인**을 받는다.
2. 승인 요청 시 다음을 명시한다.
   - 수신자(회사·이름·연락처)
   - 전달 목적
   - 자료 목록·민감도
   - 전달 수단
3. 승인이 완료되기 **전에는 전송하지 않는다.**
4. 승인 후 전달한 경우, 승인 기록과 전달 시각을 남긴다.

### 4.3 금지 행위

다음 행위는 금지한다.

1. 승인 없이 외부로 자료 전달
2. 개인 이메일·개인 클라우드·개인 메신저로 회사·고객 자료 전송
3. 비밀번호, API 키, 인증정보를 자료와 **함께** 전달
4. “급해서”, “고객이 재촉해서”를 이유로 승인 생략
5. 승인된 수신자 외 제3자에게 재전달 요청에 응하는 행위(별도 승인 필요)

### 4.4 개인정보·고객데이터

1. 개인정보 또는 고객데이터가 포함된 자료는 **마스킹·최소추출** 후 전달한다.
2. 원본 전체 파일을 외부로 보내지 않는다.
3. 필요 시 정보보호팀에 사전 문의한다.

## 5. 승인자가 부재한 경우

1. 팀장 부재 시 **본부장** 또는 **사전 지정된 대리 승인자**에게 승인 요청한다.
2. 승인자를 찾을 수 없다는 이유로 승인 없이 전달하지 않는다.
3. 긴급 상황에서도 승인 절차를 생략하지 않는다. (본 지침에 긴급 예외 없음)

## 6. 위반 시

무단 외부 전달은 징계 및 관련 법령에 따른 조치 대상이 될 수 있다. 사고 인지 시 즉시 팀장 및 정보보호팀에 보고한다.
